# Hooks that work (first 2 seconds)

The Growth agent rewrites this file from real analytics. Until then, these are the starting patterns.

| Style | Example |
| --- | --- |
| Shock reaction | "अरे बाप रे! ये क्या हो गया?" |
| Wrong confident claim | "बिजली बचाने का सबसे आसान तरीका..." (then it goes wrong) |
| Direct question to the viewer | "आपके घर में भी ऐसा होता है?" |
| Mid-action start | Start in the middle of the argument, no intro |
| Number or price | "₹5000 का बिल? सिर्फ एक बल्ब से?" |

Rules:
- No intros, no "नमस्ते दोस्तों". The first word is already the joke.
- A face or motion in the very first frame.
- Tease the punchline within 2 seconds; pay it off in the last 5.
